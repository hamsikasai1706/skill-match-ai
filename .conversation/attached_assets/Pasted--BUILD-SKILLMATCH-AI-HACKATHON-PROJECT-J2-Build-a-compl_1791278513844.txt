# 2. PROBLEM STATEMENT

Build a platform that matches candidates with jobs based primarily on skills rather than only job titles.

A candidate may have the right skills for a job even when:

- Their previous job title is different
- Their degree title is different
- Their previous experience was in another role
- They do not exactly match the job title
- They have transferable technical skills

The platform must compare:

Candidate:

- Skills
- Skill proficiency
- Years of experience
- Location
- Work preference
- Career interests

against:

Job:

- Required skills
- Preferred skills
- Experience requirements
- Job category
- Location
- Work mode

The system must calculate a transparent deterministic skill-match score.

Google Gemini should be used for:

- Match explanation
- Skill-gap explanation
- Personalized improvement suggestions
- Learning recommendations

IMPORTANT:

Gemini must NOT randomly generate the primary match score.

The core match score must be calculated by the backend matching algorithm using actual database data.

# 24. CORE SKILL MATCHING ENGINE

This is the most important functionality.

Create a deterministic backend matching service.

DO NOT use Gemini to calculate the primary score.

Use:

Required skills = 70%

Preferred skills = 20%

Experience = 10%

Formula:

requiredScore =
matchedRequiredSkills / totalRequiredSkills

preferredScore =
matchedPreferredSkills / totalPreferredSkills

experienceScore =
calculated from candidate experience and job experience range

Final:

matchScore =
(requiredScore * 70)
+
(preferredScore * 20)
+
(experienceScore * 10)

Round to an integer from 0 to 100.

Handle:

- No preferred skills
- No experience requirement
- No required skills
- Candidate with zero experience

Return:

{
  "matchScore": 86,
  "scoreBreakdown": {
    "requiredSkills": 70,
    "preferredSkills": 10,
    "experience": 6
  },
  "matchedRequiredSkills": [
    "Python",
    "SQL",
    "Node.js"
  ],
  "missingRequiredSkills": [
    "Docker"
  ],
  "matchedPreferredSkills": [
    "Git"
  ]
}

The calculation must be deterministic and reproducible.
